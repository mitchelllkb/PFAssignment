Basics of HTML & CSS

1. Hyper Text Markup Language (HTML)

HTML structure

HTML is a markup language used to structure the content of a webpage. HTML defines the structure of a webpage, which is referred to as a Document. An HTML document must begin with the following declaration:
<!DOCTYPE html>
<html lang="en">...</html>
The <html> is the root of the document where the rest of the tags will be housed within.
<head>...</head>
The <head> tag contains metadata and resources about the webpage, including <meta>,<link>,<title>,<style>,<base>,<script> and <noscript> tags. Description of each tags can be found referenced to w3schools website.
<body>...</body>
The <body> tag is where all the contents will be placed. The two kind of tags used:
Semantic: <header>, <section>, <article>, <footer>
Semantic tags clearly define their purpose and the type of content they contain. They enhance recognition by search engines and improve accessibility for screen readers.
Non-Semantic: <div>, <span> Non‑semantic tags are generic containers with no inherent meaning. Their purpose is defined only by the developer through attributes, classes, or styling.

Link to external working files

Within the <head>...</head> tags, this is where link to external files are declared.


<link rel="stylesheet" href="css/style.css"> // This is to declare to link this html file to its styling file in css folder named style.css

<link rel="icon" href="images/icon.png"> // This is to declare to set the tiny icon to be displayed at the tab of the browser.

<script src="js/abc.js"></script> // The javaScript script file can be placed here as well where the file abc.js is referenced from the folder js

Selectors

Selectors are patterns used in CSS (and referenced in JavaScript) to target specific HTML elements. They allow styles or behaviors to be applied based on the element’s type, attributes, or relationships. With <html>...</html>, HTML provides the structure by:

Tag (Type) - <p>, <section>, <h1> // Standard HTML tags. CSS type selectors apply styles to all elements of that tag.

Class - <div class="navbtn"> // Elements with class="navbtn" can be styled using `.navbtn { ... }`. Classes can be shared across multiple elements.

ID - <div id="navbtn1"> // The element with id="navbtn1" can be styled using `#navbtn1 { ... }`. IDs must be unique within the page.
